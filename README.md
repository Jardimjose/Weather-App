# City Weather

A responsive weather app. Search for a city, pick the right location from the results, and see the current weather with a three-day forecast.

Built with [Vite](https://vite.dev) and TypeScript, using the free [Open-Meteo](https://open-meteo.com) APIs (no API key needed).

## Features

- Search for a city and choose the correct match from a list of locations
- Current temperature, "feels like" and wind speed
- Three-day forecast
- Mobile-first layout that also works on desktop

## Getting started

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# build for production
npm run build

# preview the production build
npm run preview
```

## Tech

- Vite
- TypeScript
- TailWind CSS
- Open-Meteo Geocoding API and Forecast API
